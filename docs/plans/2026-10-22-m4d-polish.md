# M4d: Polish Before Go-Live (What People See) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the open follow-up findings (M1–M4c) that a person using the dashboard would notice:
- **High:**
  - error pages that miss the app frame
  - unsaved edits lost without warning
  - a first-run dead end on the website settings
  - Clerk's screens in English on `/ar`
- **Medium and low:**
  - remaining English text, plurals and screen-reader labels
  - misleading messages

**Architecture:**
- **Error boundaries:**
  - A shared error panel used by the app pages' boundary and a new `[locale]` boundary, which also covers the app frame.
  - A static bilingual `global-error.tsx` for the root layout.
- **Unsaved edits:**
  - A `beforeunload` guard while the editor has unsaved edits.
  - A confirm on the editor's Back link.
  - Ask for changes and Reject disabled until the edits are saved.
- **Everything else:** small, local changes in the module that owns each behaviour, each pinned by a test that fails first.

**Tech Stack:** Next.js 16.4 (App Router, Cache Components), React 19.3, TypeScript 5, next-intl 4.14, Zod 4.6, `@clerk/nextjs` 7.9, Vitest 5, Playwright 1.64. **One new package:** `@clerk/localizations` 4.24.0 (Clerk's own translations; depends only on `@clerk/shared` ^4.41.0, which is already installed).

- **Earlier constraints still hold:** all M1–M4c Global Constraints. In particular:
  - Cache Components: runtime data only inside `<Suspense>`
  - server-side role checks
  - Latin digits (Arabic plurals take the count as a number for the plural, and a string `{n}` for the digits)
  - logical CSS

  - every e2e test isolates the mock store
- **No new packages except `@clerk/localizations@4.24.0`.**
- **Message files:** `messages/en.json` and `messages/ar.json` keep identical keys (`tests/unit/messages.test.ts`). Merge with `python3 .superpowers/tools/merge_messages.py FILE DOTTED.PATH FRAGMENT_FILE`, which overwrites a key that already exists.

- **Mock-only behaviour:** the mock scenario `auth_crash` (the `mock_scenario` cookie) makes the test-login session read throw. The engine stays normal.

## Review Focus

1. **Unsaved edits are never lost silently.** That holds for:
   - the Back link
   - closing or reloading the tab
   - switching language (a full page load)
   - Ask for changes and Reject

   Each one either asks first or waits for a save.
   - *Pinned by:* Task 2 e2e.
2. **Any error, including one in the app frame or the session read, shows the dashboard's error page in the reader's language,** never Next's English default page.
   - *Pinned by:* Task 1 e2e.
3. **An Arabic reader sees Arabic** for:
   - the dashboard's own refusals ("Invalid request.")
   - the counts that need plural forms
   - the dialog's Close label
   - the keyword-limit hint
   - Clerk's sign-in and account screens
   - *Pinned by:* Tasks 4 and 5 (unit and e2e).
4. **First-run setup never dead-ends:** a website connection the engine hasn't created yet (404, or fields still null) opens an empty form. No secret-type setting reaches the browser.
   - *Pinned by:* Task 3 unit tests.
5. **Messages match what happened:**
   - a request the sign-in service refused
   - a "connected" notice after the account was disconnected
   - a photo too big for Vercel's request limit
   - *Pinned by:* Task 6 unit and e2e.

      return "engineInvalid";

## Decisions in M4d

These come from the plan, ahead of execution:

- **Scope:** the high-impact items (O18, O36, O37, O2) and the visible language and message items (O1, O3–O7, O9, O11). The data and robustness items go to M4e.
- **Moved to M4e:**

  - **The other medium items:** they need more design (locks, polling), or the engine's answers decide them.
- **The dashboard's own refusal keeps its code `invalid_input`,** marked with `details.source = "dashboard"`. Changing the code would have touched 41 test assertions. Error displays translate it through `failureNoticeKey`.
- **One new package, `@clerk/localizations`:** it's Clerk's own companion, at the version matching the installed `@clerk/shared`. The alternative was hand-writing Clerk's strings.
- **The Back link asks with the browser's own confirm,** like the `beforeunload` prompt it pairs with. A custom dialog would need its own focus handling for one link.
- **Photo uploads are capped at 4 MiB** (not 4.4 MB), so the limit reads as a round "4 MB".
